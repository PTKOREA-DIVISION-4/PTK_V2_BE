## 1. 실행

```bash
python scripts/evaluate_factbook.py --project-id <프로젝트ID> --pptx <내보낸.pptx 경로> --api http://127.0.0.1:8001/api/v1
```

필요 조건: 백엔드 서버 실행 중, 대상 프로젝트에 장표 초안이 생성돼 있고 PPTX 가 내보내져 있을 것. 출력은 총점·영역별 점수·감점 사유·메타데이터(JSON)다.
